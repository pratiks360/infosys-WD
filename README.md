## ✨ What Is This?

A small static site made during an Infosys onboarding exercise. `index.html` is an accordion **FAQ for new employees**; `infosys.html` and `computer.html` list common PC problems with step-by-step resolutions (reboot, close background programs, delete temp files, …).

## 📄 Pages

| File | What it is |
|---|---|
| `index.html` | FAQ: New Employees (current version) |
| `infosys.html` | "Computer issues and their solutions" (exported from Word) |
| `computer.html` | Computer-issues page |
| `index-2.html`, `index-bk.html`, `index-backup.html`, `index-old.html`, `temp.html` | Earlier drafts and backups |

## 🚀 Run / Preview

```bash
git clone https://github.com/pratiks360/infosys-WD.git
cd infosys-WD
python -m http.server 8000     # open http://localhost:8000
```

| Layer | Technology |

| **Markup** | HTML5 |

| **Behaviour** | `assets/js/main.js`, `util.js` |
